# ENIGMA — エニグマとボンベ:暗号と解読の物語

エニグマ暗号機とチューリング・ボンベを、動くデモで学べる日本語の解説サイトです。

🔗 **公開ページ:** https://kg-b0mbe.github.io/enigma/

## 内容
- 暗号の基礎(シーザー暗号・頻度分析の体験デモ)
- エニグマI 完全シミュレーター(実機と同一のローター配線・ダブルステッピング再現)
- クリブ照合・ボンベ探索(17,576通り総当たり)の体験デモ
- ポーランドの解読、ガーデニング作戦、暗号書奪取などの歴史コラム
- ブレッチリー・パーク訪問ガイド
